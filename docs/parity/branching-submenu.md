# Branching Submenu parity

Status: validated locally in batch 29; integration pending.

React contract: `src/components/ui/BranchingSubmenu.tsx`, source motion tokens and installed Framer Motion behavior. Angular authoring: `scripts/angular-branching-submenu.ts`, `packages/angular/src/branching-submenu-motion.ts`, `branching-submenu.css` and shared `animated-tabs-motion.ts`.

- Source default Build/Review data, descriptions, child lists and SVG geometry follow React. Selection initializes once; replacement input data retains stored selection and falls back to the first available parent. Empty data follows source behavior.
- Pointer selection opens a branch without changing the stored focus index. Normal tab access remains on every button. ArrowUp/Down wrap indexed selection and prevent default without reopening a closed branch; ArrowRight/Enter reopen; Escape closes without preventing default. Keyboard interaction focuses the indexed parent while open.
- Responsive geometry remains two columns, including narrow screens; source metadata's stacking claim does not describe the implementation. Selected pill, colors, radii, focus ring, font weights and light/dark demo geometry follow source.
- Wait-mode panels retain the old branch until its exit completes, use the latest pending selection, and preserve the view on reentry. Source 170/26/.9 springs and sampled-duration completion are retained. Internal replacement jumps ancestor bounds as source does; component input updates project container layout.
- Original-panel child entrance suppression lasts for that panel, including later inserted children. Later panels animate inserted children with the source 220ms curve and 35ms index delays; removed animations are cancelled. An initially empty menu animates its first later branch.
- Reduced-motion preference is captured at mount, matching the installed hook: static indicator, no layout/child movement, opacity-only panel transitions. Native root style/attribute inputs and keyboard override provide source HTML-prop equivalents; root element queries expose the actual div.
- Shared indicators preserve the fixed source layout ID, initial first-origin handoff, refreshed snapshots on parent input updates, current snapshots for remeasurement/removal, crossfades and document-scoped disposal. The optional shared-helper selector preserves Animated Tabs behavior.
