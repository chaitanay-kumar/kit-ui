# Morphing Shape Loader parity

Angular now matches React's six shape kinds, matched eight-point SVG path construction, ordered cycling, duration/hold timing, loop stopping, size, color, stroke width, fill, label and class contracts. Unique gradient IDs avoid collisions between Angular instances. Reduced motion leaves the first shape static and uses a solid fill, matching React.

Focused React/Angular desktop and reduced-motion mobile checks cover valid path geometry, size/color/stroke, path advancement, non-loop behavior, gradient versus solid fill and static reduced motion. Angular uses native CSS `d` interpolation where supported; exact Framer Motion easing frames are not claimed.
