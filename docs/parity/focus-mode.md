# Focus Mode parity

Angular now matches React's focus-card item contract, default cards, controlled input synchronization, locally mutable focus state, callback behavior, dim opacity, banner, card/quick actions and global Escape cleanup. Item `content` accepts text or an Angular `TemplateRef` as the native equivalent of a React node.

Focused React/Angular desktop/mobile checks cover focus, dimming, Exit, Escape, controlled synchronization and callbacks. CSS reproduces settled scale, border and opacity states; exact Framer Motion layout and transition frames are not claimed.
