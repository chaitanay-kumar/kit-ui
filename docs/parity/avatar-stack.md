# Avatar Stack parity

Angular now matches React's required avatar data, `max`, four sizes, three overlaps, image/initial/fallback rendering, hover tooltip, stacking order and optional overflow count. Initials intentionally derive from `alt`, matching the React implementation.

Focused React/Angular desktop/mobile checks cover fallbacks, truncation, accessible overflow labels, tooltips and hidden count/tooltip options. CSS reproduces hover lift and scale with a reduced-motion fallback; exact Framer Motion spring frames are not claimed.
