# Car Smoke Page Transition parity

Validated baseline recorded in batch 50. Integration review, merges/deployment and final user QA remain outstanding. See [batch evidence](batch-50-integration.md).

`scripts/angular-car-smoke.ts` replaces the page-summary switcher with the complete native transition and generates the full source SVG, including all three animated wheel groups. The native controller, keyframe tracks, timeline and canvas engine preserve direction, car size, timing, density/lifetime/speed-line options, vertical position, trigger content, caller classes and the application completion callback. Templates/projection replace React children. Angular's document theme class provides the counterpart of the source ThemeProvider. Generic HTML props are not spread by the actual React implementation; the native input contract follows its explicit implemented props.

The source schedules overlay fade at `carDelay + 0.65 * carDuration`, completion at `carDelay + pageTransitionDelay + 100`, and reset with its independent hold/page-duration/final-350-ms sequence. These timers intentionally remain independent, including unusual custom ordering. Reduced motion immediately shows the backdrop, invokes completion after pageTransitionDuration, then resets after resetDelay. Returned callback promises are ignored. A thrown completion still permits normal-motion reset, while the reduced-motion branch remains active until destruction. Trigger click prevents default/stops propagation even when already running; Enter and Space use the source guard.

Native per-frame writes reach the owned car, backdrop and wheel nodes directly, avoiding an extra framework render frame. The easing calculation uses Motion's bounded subdivision so the long wheel rotations retain the same angular poses. The source probe confirms Motion overrides the static half-height transform, so the native car keeps the source's actual top anchor plus animated transforms.

The canvas engine preserves frame-based smoke/skid/speed-line calculations, random draw order, particle cap and theme colors. The source initially creates a default 300x150 canvas buffer and resizes it only on a window resize event; native behavior preserves that detail, including uncapped DPR assignment and the source's coordinate conventions. Particle life advances by 16.67 per frame, not elapsed-time compensation. Density off also suppresses speed lines while skid behavior follows drift. These are source properties, not claims of corrected viewport physics or hardware performance.

Operation traces establish drawing commands; raster/GPU output and hardware performance are not asserted.

Destruction cancels native keyframes, engine frames, timers, resize/media listeners and theme observation. Late or self-destroying callbacks cannot recreate reset timers. This strengthens cleanup where the source's returned animation-stop function is not used by its trigger. Source accessibility limits remain: fixed trigger name, a focusable span containing the default button, no focus trap/restoration or completion announcement, and no Escape cancellation. The decorative overlay is aria-hidden and ignores pointer input. Navigation belongs to the application. Physical devices, Safari/Firefox, SSR/hydration and exhaustive accessibility are outside recorded coverage.
