# Code Snippet Deck parity (validated locally; integration pending)

React: `src/components/ui/CodeSnippetDeck.tsx`; authored Angular definition: `scripts/angular-code-snippet-deck.ts`; types/styles/tab adapter: `packages/angular/src/code-snippet-deck-*`, `code-snippet-deck.css`, `code-deck-tabs.ts`.

Native language and parameter defaults initialize once. Changing defaultLanguage or parameter defaults later does not reset state. An absent selected language falls back to the first snippet without rewriting the active language, so no button need appear selected. Code generators receive the retained parameter object; boolean, select and text controls update it. Empty code has one blank line; numbered highlights and trailing/blank lines follow the source. Flags control line numbers and window dots. Native root HTML overrides use typed attributes/style inputs and explicit event callbacks.

Copying is optimistic, bubbles to the root, and schedules an independent two-second reset per click, including clipboard failures. It preserves the source fallback textarea behavior; native destruction additionally cancels pending resets. There is no failure alert or live copy announcement. Language controls remain ordinary buttons; metadata's tab roles and arrow-navigation claims are not implemented by React and are not invented here. Text/select parameter captions are not programmatically associated labels in the source.

The tab adapter reuses the validated shared-layout projection/crossfade controller with a unique per-deck identity and the source 380/30/.5 spring. The source keeps animation under reduced preference; browser sampling verifies that behavior. The config caption's actual 11px/14.6667px line height is preserved; assuming 1.5 changed mobile wrapping height. Colors remain hardcoded dark values even in light theme.

Packaged contracts pass mount-only state, generator changes, fallback selection, blank/highlight lines, empty code, overlapping denied-copy resets, root overrides and timer/frame disposal. Main browser coverage passes live parameter controls, native keys, replacement data, clipboard failure/fallback, propagation, disposal, flags and demos. Dark/light desktop/mobile comparisons and shared-tab motion checks pass after the caption correction. Final evidence is recorded in [batch 39](batch-39-integration.md).
