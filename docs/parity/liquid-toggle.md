# Liquid Toggle parity

React's `LiquidToggle` is the reference. Angular now exposes the same controlled `value`, uncontrolled `defaultValue`, boolean callback, labels, disabled state, accent color, class hook, internal-label option and dimensions.

The root is a native button with `role="switch"`, changing accessible label and `aria-checked`. Click, Space/Enter and directional arrows follow React, including no duplicate callback when an arrow already represents the current state. SVG gradient IDs are unique per instance.

Focused validation covers click and directional keyboard changes, controlled requests, labels, dimensions and disabled state in rendered React and Angular consumers on desktop/mobile. Angular uses deterministic endpoint blob paths with a CSS transition; React derives intermediate deformation from Framer Motion spring velocity. Exact in-flight silhouettes are not claimed.
