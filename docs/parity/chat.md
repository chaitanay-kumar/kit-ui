# Chat parity

Validated baseline in batch 49. See the [batch evidence](batch-49-integration.md) for commands and results. Subsequent hosted QA and deployment evidence are tracked in [the active QA brief](hosted-qa.md); exhaustive state/pixel acceptance remains outstanding.

`scripts/angular-chat.ts` owns the native root and compound definitions. `chat-context.ts`, `chat-message-state.ts`, `chat-motion.ts` and `chat-types.ts` preserve the externally owned message, generation, thread and transport contract. The public native surface includes root, header, sidebar, message, messages and composer components, `injectChat`, typed context and the projected-content marker. Angular templates replace React node content; externally declared templates receive the root injector. Standalone messages do not require root context.

Sending trims text and permits attachment-only submissions. File selection records name, generated ID, MIME-derived image/file type and formatted size; it supplies no file upload. Synchronous callback failure preserves draft and attachments. Returned promises are ignored and do not own loading state. Generation blocks sending while leaving editing and attachment controls active. Default message lists do not supply retry callbacks; standalone messages can request retry by ID. The content renderer follows the source's small inline/fenced-code parser, including escaped HTML and incomplete fences; it is not a Markdown engine.

Copy feedback is optimistic even if clipboard permission fails or the fallback returns false. Each click retains its own two-second reset, so an earlier timer can clear feedback from a later click. Native destruction cancels pending resets. Message entry and attachment presence preserve the source 320/34/.7 spring; press feedback follows Motion's default scale spring. Reduced motion makes message entry reach its final pose on the next frame and disables press scaling. Attachment springs and smooth scrolling remain active under reduced motion, as in the source. Native animation frames, press/media listeners and spacing observers are owned by the mounted components and released on destruction.

Recorded passing checks: 20 desktop/mobile light/dark layout/style comparisons; 28 renewed paired behavior cases; 12 clipboard cases across successful/rejected secure clipboard and false fallback; 20 paired motion cases including interrupted attachment exit and reduced motion; eight composer growth, attachment-only sending and external scrolling cases; 33 actual React-rendered parser comparisons; and the focused packaged ownership, callback, context, timer/listener/observer/frame disposal and recursive-source check. Four shared light/dark consuming-demo cases also pass. The batch baseline passes component/Angular sync, production build with 289 SEO checks, 117 unit tests, lint with 34 inherited warnings and strict installed-tarball consumers on Angular 20.0.0, 20.3.33, 21.2.25 and 22.2.1.

Caller classes use the same `tailwind-merge` dependency as React. Scoped, precompiled defaults preserve responsive and dark variants without requiring a consuming Tailwind compiler; custom utility classes still need corresponding application CSS and Kit UI theme tokens. Source downloads include the class dictionaries and recursively imported helpers.

Source accessibility limits remain explicit: the composer uses a placeholder without linked label/description IDs; attachment-removal buttons are unnamed; the mobile sidebar has no focus trap, focus restoration or Escape dismissal; offscreen controls are not made inert. Native controls retain their standard keyboard behavior, and Enter/Shift+Enter preserve source composer shortcuts. Sending/sent/delivered statuses share the same rendering. The application owns authentication, persistence and live transport. Physical devices, Safari/Firefox, SSR/hydration and exhaustive accessibility are outside the recorded scope.

Hosted QA aligns the native consuming demo with React's data-table sample, authors/timestamps, thread groups, 1200 ms simulated reply and new-conversation behavior. Both demos now own and cancel pending replies on clear, new conversation and destruction; the Chat transport API is unchanged. Demo flex wrappers permit shrinking on mobile, the iframe supplies the reference send-button background token, and the packaged fenced-code renderer supplies the same monospace default without requiring the React global stylesheet.

Message lists defer their existing smooth `scrollIntoView` by one owned frame so transparent-host spacing can settle before the target is measured. Updating or destroying the view cancels a pending scroll; the packaged verifier checks deferred execution and disposal. Hosted diagnostics also show React's default endpoint varying between 151 and 152 px. The comparison records both unmodified default scroll positions, then explicitly scrolls both message lists to the bottom and asserts equal scroll metrics before comparing their geometry. It keeps the 0.8 px geometry threshold and all painted-style assertions.

The hosted regression checks matching initial text, painted styles/borders and visible geometry plus send/reply and pending-reply cancellation in both themes/viewports. Hidden zero-size positions, zero-width border colors and the closed offscreen sidebar footprint are not painted comparisons. Initial crops temporarily gain vertical room at unchanged width/DPR to avoid the fixed framework chooser; geometry and interactions use the original device viewport. Opened sidebar whole-page versus iframe geometry and exact compositor/animation raster identity remain to be reviewed.
