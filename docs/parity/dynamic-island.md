# Dynamic Island parity

Validated baseline in batch 49. See the [batch evidence](batch-49-integration.md) for commands and results. Integration review, merges/deployment and final user QA remain outstanding.

`scripts/angular-dynamic-island.ts` replaces the generic collection with native collapsed, expanded, profile and share templates. `dynamic-island-state.ts` owns controlled requests, mount-owned uncontrolled defaults, social normalization and document interactions. Angular templates replace React node content. Expanded content supplements its body; truthy profile/share content replaces the default body. Native component hosts preserve the source region's layout participation without an extra wrapper.

Social arrays retain their supplied item values; object entries normalize platform labels, skip falsy links and add `mailto:` only for object email entries. Missing socials produce the source's five defaults. Avatar fallback, alt text, greeting, metadata and optional content follow the source. `idPrefix` namespaces the avatar layout key; generated IDs isolate ordinary instances. Cross-instance shared-layout handoff using deliberately duplicated prefixes is outside the recorded validation.

`dynamic-island-motion.ts` implements root projection with the source 400/30/.8 spring, 200 ms content fades, shared-avatar projection/crossfade and retained outgoing content. Avatar exits can remain mounted after fading until the layout spring completes. Interrupted transitions preserve the painted pose and spring velocity. Reduced motion commits the final state without interpolation; paired comparisons check every presented frame, while the source's synchronous pre-paint cached projection is excluded only for duration-zero transitions. State-specific corner classes remain discrete, matching the source rather than the former metadata claim of continuous radius interpolation.

The renewed focused suite passes 54 desktop/mobile cases: 16 behavior, 16 resting layout/style and 22 motion comparisons including three reversals. Eight additional collapsed/profile caller-class comparisons pass across light/dark and desktop/mobile. Four shared consuming-demo cases pass. The packaged contract passes controlled/default ownership, social normalization, active-animation destruction, reduced motion, document/media cleanup and recursive source closure. The batch baseline passes component/Angular sync, production build with 289 SEO checks, 117 unit tests, lint with 34 inherited warnings and strict installed-tarball consumers on Angular 20.0.0, 20.3.33, 21.2.25 and 22.2.1.

Caller classes use React's `tailwind-merge` semantics. The package ships scoped default utility CSS and native SVG geometry without React or a consuming Tailwind build. Custom utilities and Kit UI theme tokens remain the consuming application's responsibility. Source downloads include the generated class dictionary and all imported native helpers.

The source uses native buttons/anchors with Escape and outside-pointer collapse; it does not provide focus trapping or restoration. CSS pulse effects remain unchanged by the reduced-motion preference. Recorded browser checks use Edge Chromium with desktop/mobile emulation; physical devices, Safari/Firefox, SSR/hydration and exhaustive accessibility are outside their scope.
