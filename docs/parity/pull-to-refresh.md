# Pull to Refresh parity

Validated baseline recorded in batch 50. Integration review, merges/deployment and final user QA remain outstanding. See [batch evidence](batch-50-integration.md).

`scripts/angular-pull-to-refresh.ts` replaces the generic action port with the source gesture container and exports the standalone FinancialStatsCard. Native controllers preserve callback ownership, configurable threshold/max/resistance/hold, disabled state, custom indicator state/templates, content projection, wrapper attributes/events and caller classes. FinancialStatsCard preserves controlled/internal range selection, data-map fallback, pointer scrubbing, price/context formatting, trend colors, optional metrics and deposit/withdraw callback identifiers.

The pull curve is exponential. A release can refresh after reaching the damped threshold or through downward flick velocity; pointercancel uses the same release path. Button/chart targets and scrolled descendants suppress gesture starts. R without Control/Meta triggers refresh, including from descendants. An explicitly supplied wrapper pointer/keyboard handler replaces the corresponding internal handler; explicitly undefined handlers also suppress it until removed. Caller attributes override defaults and removing them restores those defaults.

Refresh callbacks can be synchronous or asynchronous. Failure silently returns idle, with no invented alert/retry transport. Without a callback, the source financial simulation waits 1100 ms and updates its data; completion holds for 380 ms before returning. The source allows another keyboard/button refresh during the complete hold, and an older hold can reset a later refresh's state. Upward movement retains the previous pull-distance ref until release. Native behavior preserves these recorded details. Destruction cancels owned waits and suppresses late external callback state changes.

The rendered body now paints in the motion frame; four paired desktop/mobile hold/return checks preserve the original .15 px limit, with all sampled translations exactly equal. The native raw spring and post-render 380/28/.65 follower match Motion's recorded gesture/hold/return/retarget frames. Reduced motion removes body translation but retains the source's unconditional refresh spin, completion/arrow springs, pulse and shared tab-pill projection. Financial price entries preserve 180 ms pop-layout fade/vertical movement/blur, fractional exit dimensions and interruption. Chart fill/stroke, change text, endpoint and pulse effects use the source keys, easings and spring parameters. Native frames, media/global listeners and shared-pill membership are released on destruction.

Focused evidence includes 34 actual-source data/curve/resistance/simulation comparisons, ten actual-source lifecycle scenarios, two native session destruction cases, browser layout/behavior/motion subsets and a passing packaged ownership/disposal/source-closure check. The combined desktop/mobile suite passed all 162 cases. Production build, 289 SEO checks, lint, 117 unit tests, final packaged contracts and all four installed-tarball compiler consumers pass. The final affected pull/demo browser renewal passes 58/58 cases after correcting native frame painting. The batch brief records commands and evidence.

Source accessibility limits remain explicit: the chart is aria-hidden and pointer-only; all range tabs have tabindex 0 without arrow-key navigation; the default progress indicator is aria-hidden without a live announcement; panel shortcuts do not filter editable descendants; and the panel removes its outline. The hidden native refresh button and aria-busy region remain available. Numeric configurations follow source arithmetic rather than adding validation. CSS/theme tokens and custom utility styles are application responsibilities; default scoped styles are precompiled. Physical devices, Safari/Firefox, SSR/hydration and exhaustive accessibility are outside recorded coverage.
