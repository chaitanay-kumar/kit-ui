# OriginDropdown parity

React's `OriginDropdown` is the reference. Angular now supports controlled or uncontrolled open state, four sides, placeholder or template triggers, item lists, template menu content, template item icons and the open-change callback.

Menu items retain disabled, destructive, description and `onSelect` behavior. Selection closes an uncontrolled menu. Escape and outside pointer dismissal request closure, and document listeners are removed on destruction. Controlled consumers receive requests without Angular mutating their bound state.

Focused validation covers selection, disabled items, Escape, outside dismissal, controlled updates, side placement and custom content in rendered React and Angular consumers on desktop/mobile. Angular uses CSS origin animation; exact Framer Motion entry/exit spring frames and exit-presence timing are not claimed.
