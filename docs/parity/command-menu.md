# Command Menu parity (validated locally; integration pending)

React source: `src/components/ui/CommandMenu.tsx`; authoring: `scripts/angular-search-palettes.ts`; native controller, presence/highlight support, glyphs and styles: `packages/angular/src/search-palette-*`, `search-palettes.css`.

The generic Liquid Command Palette wrapper is replaced with the source's required controlled isOpen/onClose contract. Catalog entries come from the same generated React catalog at authoring time, followed by the five actual documentation actions, CLI-copy action and repository action. Filtering is case-insensitive title/category substring matching, not fuzzy search. Query and index persist through closing; input changes reset index. Keyboard navigation wraps globally while open. Ctrl/Meta+K prevents default even while closed and never opens the component itself; Escape requests close without preventing default.

Selection preserves navigation/copy/close order and synchronous failure short-circuiting. Clipboard rejection is ignored after optimistic close; the fallback textarea follows the source helper. Repository opening uses the source URL and target/features. Backdrop clicks pass their event directly to captured onClose; other close paths invoke it without an argument. Native callbacks receive native DOM events and Angular ErrorHandler receives synchronous observer exceptions without inventing event cancellation. Exit snapshots preserve old callbacks, query/index and visible labels.

The fixed overlay, source glyph geometry, responsive horizontal padding, 380/30/.5 panel spring and 300ms default backdrop transition replace the unrelated wrapper UI. Native disposal releases global listeners and animation frames. It does not add focus restoration, a focus trap, body overflow locking, automatic result scrolling, a combobox or an error announcement absent from React. The input relies on its source placeholder; listbox/options remain as authored. Animation continues under reduced preference, matching the source runtime.

Focused packaged contracts and paired desktop/mobile behavior checks pass. Paired light/dark geometry (within 1 px), typography, painted shadows, glyphs and desktop/mobile screenshot inspection pass; badge/category line height follows the measured 13.3333px source value.
