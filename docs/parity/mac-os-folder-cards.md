# macOS Folder Cards parity

Source: `src/components/ui/MacOSFolderCards.tsx`; native authoring: `scripts/angular-folder-cards.ts`, with folder types, SVG geometry, card template, CSS and motion in `packages/angular/src/folder-*`. The former generic selectable collection is replaced by the source porcelain folder and expanded grid.

The four source items, descriptions, metadata and icons are preserved. Items use MacOSFolderCardItem; icon content accepts native TemplateRef/scalars or a typed built-in icon descriptor. Projected SVGs retain supplied dimensions/inherited color; built-in sizing/color is scoped to its own icon class. Falsy icons use Layers and falsy metadata uses the source `0${index+1}` fallback. SVG geometry comes from the installed Lucide version, with shipped attribution. The closed pocket always has three decorative layers; only its front label reads the first item. Empty items retain the folder/header rather than rendering no component.

`defaultOpen` initializes local state once; later changes do not control it. `isPeeked` controls hover independently, otherwise local mouse hover applies. The closed trigger has role button, tabindex, Enter/Space activation and a constant false aria-expanded while present. Installed Motion also makes the tap-enabled inner body a focus stop; native preserves it and removes that stop on a reduced-motion mount. Open content has a native close button and decorative hoverable articles. The open grid has no global Escape or selection handler in React. `folderCategory` is forwarded as a scalar DOM attribute, not rendered as the metadata's claimed breadcrumb.

Native wait-mode transitions retain the departing view until its 170/26/.9 spring completes, including interrupted/reversed requests. Body hover/tap uses 380/30/.5; peek layers use 350/25 and animate into their initial rotated/scaled pose; flap motion uses 350/24 with bottom-center 3D origin. Card entry/hover uses 350/26, including index*30ms delay on hover and release. Independent property delays keep opacity entry running if y retargets. Reduced motion suppresses interactive peek/tap/card transforms and article entry; source outer transitions and resting peek mount animation remain enabled.

Root className, numeric CSS via style, scalar attributes and native onClick/onKeyDown inputs provide the recorded HTML adaptation. Replacing scalar inputs/data preserves the source state semantics. Synchronous callback failures are reported through the native ErrorHandler on the next microtask, preserving propagation/default actions and explicit preventDefault. Native keyboard/pointer handling and owned window listeners/frames dispose on unmount. Migration: replace label/selected/disabled/execute/itemSelect and KitItem label/value data with folderTitle, typed items, defaultOpen and isPeeked. Applications own any additional card actions; the source provides none.

Validation: focused packaged contracts and the recorded 76-case cross-batch desktop/mobile scope pass, including fresh mount/hover/stagger/reversal, keyboard focus/press, source data/root overrides, callback recovery/defaults, projected bare SVG content, actual demos and disposal. Final production/289 SEO, 117 unit tests/lint and four independent Angular compiler consumers pass. See [batch evidence](batch-36-integration.md) for commands, renewed artifacts and exact scope.

Scope limits: the source uses a fixed white/dark palette, including near-white folder labels that have poor contrast on a light canvas. This behavior is retained and does not establish full contrast conformance. No automatic focus restoration, controlled open state, server-rendered output, physical-device or other-engine coverage is claimed. Supply matching fonts/theme tokens; arbitrary Tailwind class conflict resolution is outside this baseline.
