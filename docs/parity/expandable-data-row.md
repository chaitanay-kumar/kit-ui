# Expandable Data Row parity (validated locally; integration pending)

React source: `src/components/ui/ExpandableDataRow.tsx`; native authoring: `scripts/angular-expandable-data-row.ts`. The generic details collection is being replaced with typed account rows, responsive layouts, source defaults, retained detail transitions and application callbacks.

The source initializes expanded IDs once, defaults to usr_01, and retains them across loading/data changes. Single mode toggles one row; multiple mode preserves other expanded IDs. User avatars, roles and sessions exist in the data type but are not rendered by React. Metadata uses truthy fallbacks. Copy stops propagation, gives optimistic feedback immediately and schedules an independent two-second reset on every click, regardless of clipboard resolution. Native cleanup cancels pending resets on destruction. Row actions preserve the original item object and source action strings.

Evidence: `node scripts/verify-parity-batch37.mjs` passes packaged defaults, mount-only state, original action payload, failed copy, independent overlapping resets, source fallbacks, retained exits and timer/frame disposal. Edge desktop and Pixel 7 emulation pass native Space/Enter, single/multiple expansion, loading/empty/replaced data, denied clipboard propagation, action failure recovery, fallback copying, optimistic feedback reset, interrupted exits, unmount and the actual native demo callback. Paired browser assertions compare every visible button/paragraph's geometry (within 1 px), font, size, line height, radius and color. Desktop/mobile screenshots were inspected; the native row font was corrected to React's actual Inter output. Batch 37 has 46 passing unique browser cases across its main and focused follow-up runs. Full baseline and compiler details live in [the batch brief](batch-37-integration.md).

Motion uses the shared 170/26/.9 detail presence and 380/30/.5 chevron spring. Initial expanded content is staged without entrance motion; interrupted exits can reopen. Runtime frame sampling confirmed React keeps chevron motion when reduced motion is requested. Angular now preserves this behavior; the paired reduced-preference regression passes. This is a source limitation, not a reduced-motion compliance claim. Frame-by-frame pixel equality is not asserted.

Other preserved source limits: desktop rendering uses a visual grid rather than table roles; copy feedback has no live announcement; colors are hardcoded dark values. Copy feedback reports the click optimistically rather than clipboard success. The fallback moves focus to a temporary textarea; a throwing `execCommand` is not recovered by the source helper. Native destruction additionally cancels feedback timers, while React leaves its timers scheduled. No general WCAG or physical-device coverage claim is made. Older callback/standards audits and final user QA remain separate tracker work.
