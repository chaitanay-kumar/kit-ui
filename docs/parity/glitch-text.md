# Glitch Text parity

Angular now matches React's required text, five variants, three triggers, color aliases and precedence, three intensity levels, timing, click callback, scramble reveal, unique instance ID and reduced-motion listener/cleanup. The `as` compatibility input is reflected as `data-as`; Angular's compiled component cannot replace its runtime host tag, so consumers choose surrounding semantic markup in their template.

Focused React/Angular desktop and reduced-motion mobile checks cover layer counts, variant changes, click callbacks, scramble readability and ghost removal. CSS approximates Framer Motion transforms, slicing, VHS and pulse frames; exact keyframes and repeat-delay phasing are not claimed.
