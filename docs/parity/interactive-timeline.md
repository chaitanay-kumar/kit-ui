# Interactive Timeline parity (validated locally; integration pending)

React source: `src/components/ui/InteractiveTimeline.tsx`; native authoring: `scripts/angular-interactive-timeline.ts`. The generic filter/inspect collection is being replaced with typed timeline status nodes, independent selection/expansion, progress, details and commit copying.

Selected ID and expanded IDs initialize once and persist across data changes. Selection updates before onItemSelect; if that callback throws, expansion does not run. Noncollapsible mode retains initial expansion and still selects/calls back. Progress follows the last completed/in-progress item index, including noncontiguous statuses. Empty input still renders the region/list. Copying a hash stops propagation and uses optimistic independent two-second feedback resets.

Evidence: native Angular APF/demo build and focused packaged contracts pass callback identity/failure ordering, independent expansion, noncollapsible state, last-active-index progress, root overrides, data mutation, empty retention and timer/frame disposal. Edge desktop and Pixel 7 emulation pass native Enter, failed selection recovery, copy propagation, clipboard fallback/reset, interrupted exits, unmount, replacement data, root role/style overrides and the actual native demo. The content-div Enter regression confirms source content does not acquire invented keyboard activation. Paired visible button/paragraph geometry (within 1 px), typography, colors and radii pass; desktop/mobile screenshots were inspected. Native circles now use the same unlimited-radius expression as React. Batch 37 has 46 passing unique browser cases across main and focused follow-up runs. Full baseline/compiler details live in [the batch brief](batch-37-integration.md).

Motion uses 170/26/.9 detail/progress springs and a 200 ms ease-out chevron. The cubic-bezier easing was corrected to match the source tween. Initial details skip entrance motion and exiting details can reopen. Runtime sampling and browser regressions confirm React keeps chevron motion with reduced motion requested; Angular preserves it. CSS spin/ping and source motion do not establish reduced-motion conformance. Frame-by-frame pixel equality is not asserted.

Preserved source limits: status nodes are keyboard accessible, while clickable content divs have no role/tabindex/keyboard activation. The visible hash supplies the copy button's accessible name; status nodes use title text. Aria-controls points to an absent detail element while collapsed. Colors are hardcoded dark values. Copy feedback is optimistic; fallback copying temporarily moves focus and does not recover a throwing `execCommand`. Native destruction additionally cancels feedback timers. Angular exposes root HTML overrides via typed `attributes`/`style` inputs and explicit click/key callbacks. No general WCAG or physical-device coverage claim is made. Older audits and final user QA remain separate tracker work.
