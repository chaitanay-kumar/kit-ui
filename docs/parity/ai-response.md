# AI Response parity

Validated baseline: AI Response completes recorded coverage for all 116 catalog components. Integration and deployment status are recorded in the feature brief. See the [feature brief](ai-response-integration.md).

The dedicated definition in scripts/angular-ai-response.ts replaces the generic timed-text port with the React compound contract: root, Header, Content, Sources, Actions, ToolsSummary and standalone CodeBlock. Native context resolves the nearest root, supports projected and TemplateRef composition, and provides signal getters as the Angular counterpart of the React context hook. Application content, status, model name, citations and callbacks are inputs; the component does not request a model, simulate a stream, or own transport cancellation.

The limited parser preserves source headings (levels one through three), plain paragraphs, bullet lists, blockquotes, pipe tables and fenced/incomplete code blocks. Inline support is non-nested bold, code and links; headings/table cells stay literal. HTML is text, code has no syntax highlighting, and tool status is accepted but not displayed. Unsupported hash-prefixed lines previously caused a non-progressing React parser loop; both parsers now consume those lines as paragraphs, with a regression test. Source comparison checks cover 21 block cases and 14 actual React-rendered inline cases.

Response and code copies preserve optimistic feedback, secure clipboard/fallback text selection, synchronous failure ordering and independent 2000 ms resets. A failed clipboard promise still shows copied feedback, as in React. An older click may reset newer feedback; code and response timers remain independent. Feedback toggles before its callback and remains local across content/status updates. Regeneration is disabled only while generating or streaming. Native event callback failures are reported without implicitly cancelling the DOM event. Returned promises are not transport controls.

Source disclosure uses the explicit source override or root sources, with mount-owned default expansion, target/rel link behavior, snippets and responsive columns. Tool disclosure is standalone, has its own mount state, and toggles before invoking its callback. Both retain exiting rows, release retained state after completion and preserve interruption/reversal. Expansion is an unconditional 300/32/.6 spring; press scales are .96 for copy/regenerate, .94 for feedback and .98 for tools. Native frame history follows MotionValue velocity semantics, including final clamps and per-axis completion. Reduced motion disables press transforms but leaves source/tool expansion and CSS spin/pulse effects active.

Native destruction cancels copy resets, active press/presence frames and press listeners. Destroyed contexts and synchronous clipboard-triggered destruction cannot recreate copy timers. This strengthens cleanup beyond the source's unowned timeout callbacks. Precompiled scoped utility styles preserve caller class merging; custom classes/theme/font variables remain the consuming application's responsibility. The native demo clearly labels its local simulation.

Accessibility follows the recorded source: content has a polite region only while streaming, generating/error branches use status/alert, buttons are keyboard-native and source disclosure exposes aria-expanded. Tool disclosure has no aria-expanded, feedback has no aria-pressed, and copy labels optimistically report success without a live region. No additional focus manager or network cancellation is implied. Physical devices, Safari/Firefox, SSR/hydration and exhaustive accessibility certification are outside the recorded baseline.

Validation passes: component/Angular synchronization for 116 entries; full build and 289 SEO checks; 118 unit tests in 15 files; lint with 34 inherited warnings; packaged native contracts and parser comparisons; installed-tarball strict consumers using Angular 20.0.0, 20.3.33, 21.2.25 and 22.2.1. Browser coverage includes 40 paired layout cases (two themes, desktop/mobile), 40 paired presence/press motion cases, 40 control cases and four consuming-demo cases. The full run passed 123/124; the remaining mobile test had an asynchronous label locator race. Waiting for its existing copied-state assertion fixes that test; all 12 repeated React/Angular desktop/mobile nested-owner cases pass. Runtime code was unchanged by that correction. All 124 distinct cases therefore have passing evidence; no tolerance or assertion was weakened.

Layout compares computed styles and DOM text with box deltas below 0.8 px. Motion compares height below 0.15 px, opacity below 0.002 and press scale below 0.0002. The controlled motion fixture selects the actual React Motion JavaScript backend before imports; this does not certify GPU/raster behavior or physical devices. Final user QA remains outstanding.
