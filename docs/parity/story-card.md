# Story Cards parity

Source: `src/components/ui/StoryCard.tsx`; native authoring: `scripts/angular-story-cards.ts`, with story data, navigation lifecycle, keyed slots/content, navigation buttons, CSS and motion in `packages/angular/src/story-*`. The generic selectable collection is replaced by the actual responsive story carousel.

Four source default stories are preserved; their third/fourth descriptions and CTA differ from Stacked Cards. `initialIndex` initializes a continuous local virtual index once. Six slots [-1..4] are keyed by virtual index and map through wrapped real indices. Next/previous and preview clicks apply the source non-loop bounds; even non-looping mode still displays wrapped preview data. Changing cards retains the virtual index; same-reference mutations/reordering are observed when the consuming Angular view requests a check, corresponding to a React consumer rerender. Zero cards render no section; undefined restores defaults. One card still renders six wrapped slots but disables stepping/timers/global arrows and hides navigation controls.

Source navigation is retained: global ArrowLeft/Right exclude inputs, textareas, selects and editable targets; wheel chooses the dominant axis, ignores magnitude below 18 and throttles accepted events for 320ms without preventing browser scrolling. Horizontal touch displacement must exceed 40 and the vertical displacement. `showNavigation` affects native previous/next buttons only. Autoplay clamps its interval to at least 1200ms, pauses on hover and is suppressed by the reduced-motion mount snapshot. Root mouse-enter/leave callbacks replace internal hover handlers, matching React spread ordering. Synchronous callback failures report through the native ErrorHandler on the next microtask, preserving browser defaults/propagation and explicit cancellation. Timers/listeners clean up on data changes and unmount.

Viewport staging is 82/13/5% below 640px, 74/15/8/3% below 1024px and actual 68/12/8/6% on desktop; source comments incorrectly describe desktop widths. Exiting margin compensation is -10/-12px. Slots preserve initial=false staging, 150/24/.8 springs for width/margin/opacity and source interruption velocity; CSS unit springs use Motion's 0..100 interpolation, 30ms velocity expiry and clamped finite-difference velocity. Paired idle-navigation samples pass on desktop and mobile. Active content retains its prior card through 280ms exit with a 50ms delay and wait-mode replacement. Hover scale remains enabled with reduced motion, using immediate slot transitions; image CSS hover scaling also remains. Navigation-button scale uses the installed 550/30 spring, primary pointer filtering and Enter press/blur cancellation. Space keeps its native button click without the source press animation.

Native images preserve nullish alt fallback (empty alt stays empty), eager active/lazy preview loading and non-draggable behavior. Optional description, href and nullish CTA label rules match source, including active links stopping propagation and summary links appearing only with a description. Title/subtitle, live story label, className, scalar attributes, numeric styles and native root callbacks are supported. Migration: replace items/selected/itemSelect/execute with cards, mount-only initialIndex and the actual carousel options; React has no controlled selection/change callback contract here.

Validation: focused packaged contracts and the recorded 76-case cross-batch desktop/mobile scope pass, including tablet resizing, both themes, virtual data/mutation/bounds, wheel/touch/global keys, autoplay/override callbacks, reduced motion, source link/default/error semantics, intermediate slot/content/nav motion, bare/demo use and disposal. Final production/289 SEO, 117 unit tests/lint and four independent Angular compiler consumers pass. See [batch evidence](batch-36-integration.md) for commands, renewed artifacts and exact scope.

Source accessibility limits are retained: preview divs have role button/tabindex but no Enter/Space activation, and no visible focus ring on the slot. Arrow keys and native navigation/link controls remain usable. This baseline does not claim full accessibility conformance, pointer-drag support, server-rendered output, physical multitouch, other engines or arbitrary Tailwind conflict resolution. Use valid integer indices/unique IDs and matching fonts/theme tokens; source does not sanitize invalid fractional indices or clone identities.
