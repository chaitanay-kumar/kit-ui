# Scroll Velocity Text parity

Status: validated locally in batch 28; integration pending.

React contract: `src/components/ui/Scrollvelocitytext.tsx` and types. Angular authoring: `scripts/angular-scroll-velocity-text.ts`, `packages/angular/src/scroll-velocity-motion.ts` and `scroll-velocity-text.css`.

- Required continuous text, defaults/undefined values, polymorphic tag, class/style/attribute bindings, transform origin and window/container targets follow source. Custom elements create SVG/MathML namespaces where appropriate; native `[kitScrollVelocityText]` usage preserves native HTML bindings and event currentTarget. `element` exposes the rendered node for Angular consumers.
- Signed scroll distance accumulates in a clamped target, scales by distance/intensity, and drives spacing/scale/fade through frame-independent exponential damping. Idle progress holds; RAF sleeps after settling. Window top resets the target, and resize resets the last observed scroll baseline.
- Distance/intensity/smoothing bounds and dependency equality match source. Progress is retained when changing tags or relevant inputs; style reconciliation preserves direct motion writes when style inputs have not changed. Numeric CSS units, cssFloat and boolean versus ARIA attributes are handled.
- Runtime reduced motion resets/cancels motion. Initial reduced-motion mount installs no scroll/resize listeners; enabling motion alone leaves them absent until a relevant effect dependency changes, preserving source behavior. Cleanup removes media/scroll/resize listeners and frames.
- Native showcase uses the source container, text, range, directional buttons/reset, defaults and actual Lucide paths. Consuming examples include required text and are compiled with the installed package.
