# Form parity

Integrated implementation baseline from batch 47. Hosted state and pixel QA remains ongoing.

The native Form replaces the generic schema/transport proxy with a composable root and all 12 supporting exports: FormItem, FormLabel, FormControl, FormDescription, FormMessage, Input, Textarea, Select, Checkbox, RadioGroup, RadioGroupItem and Switch. These are standalone Angular components. Native `TemplateRef` content/projected children replace React nodes; typed `element()` queries and `focus()` replace forwarded refs. Named control inputs and scalar `attributes`/`style` maps target the actual native element. `events` forwards typed native DOM events; callbacks receive native events rather than React SyntheticEvents.

Authoring: `scripts/angular-form.ts`. Supporting implementations: `packages/angular/src/form-parts.ts`, `form.css`, `form-icons.ts`, `form-motion.ts`, `form-spacing.ts`, `form-native-bindings.ts` and `form-native-events.ts`. Geometry uses source defaults and springSnappy constants. Angular transparent hosts are flattened for the source's logical end spacing, including conditional error presence. Spacing observers and control springs are disposed. Icons reproduce installed Lucide geometry with its license included; no React runtime is used by the native package.

Text controls preserve controlled/uncontrolled values, mount defaults, native reset values and password visibility across type changes. Password buttons retain the source's negative tab index and remain usable when the input is disabled. Select supports native options, projected options, multiple values, mode changes and the source's enabled-option fallback. Options and radio items track source value keys, retaining native identity on reorder. Checkbox, radio and switch ownership follows the source's controlled/default behavior. Root validation is disabled by default; explicitly undefined noValidate overrides that default to false, as it does in the React root's trailing props spread. Submission callbacks decide cancellation and application validation; the component does not introduce a transport.

The focused browser suite covers 36 behavior cases, four standalone radio callback/error cases, 22 paired geometry cases, four native binding cases, 16 motion/interruption cases, four explicit noValidate cases and eight numeric-content cases across desktop/mobile Chromium. Geometry comparisons assert native tags, typography, color, border, padding, spacing and measured rectangles. Behavior includes callbacks/default restoration, keyboard selection, disabled boundaries, native resets, error exit/reentry and explicit cancellation. Standalone radio input changes preserve their event argument, while visual-circle callbacks receive no argument, following the source's two invocation paths. Actual animation frames establish intermediate check/switch/shared-radio motion, reversal and retained message identity. These checks do not establish every animation trajectory under every interruption.

Numeric zero in icon/label slots preserves React's short-circuit rendering. The corresponding Input, Checkbox and RadioGroupItem screenshots are byte-identical. Switch geometry is exact, but repeated React renders themselves vary at its fractional circular edge. Its image assertion keeps all pixels outside the thumb/shadow exact, requires unchanged alpha and geometry, and limits RGB differences to two levels within a two-pixel circular contour budget. This is an anti-aliasing allowance, not a different shape or motion implementation.

The packaged contract constructs every export, verifies native refs, callbacks/defaults and reentered message bindings, checks complete downloaded dependencies, and asserts frame/observer/listener disposal. A failed reentry test exposed stale bindings tied to the removed paragraph; FormPart now replaces its bindings when the element changes. Static IDs are removed from custom field hosts to avoid duplicate IDs preventing real label association.

Source limitations are preserved and documented: FormLabel's required flag is decorative; associate ordinary labels explicitly. Root noValidate means native required constraints do not automatically gate submission. Password toggles are omitted from tab order; custom visual checkbox/radio surfaces do not gain new keyboard semantics. Source form springs have no component reduced-motion bypass. Native DOM events/refs and Angular immutable input updates are framework equivalents, not a React DOM or SyntheticEvent compatibility layer. SSR/hydration, physical devices, Safari/Firefox and exhaustive accessibility are not established.

See [batch evidence](batch-47-integration.md) for baseline commands, consuming demos/recipes and strict installed-package results. Metadata now describes actual requirements/associations and imports Button from its own module.

Batch baseline passes: component/Angular sync, production build with 289 SEO checks, all 117 unit tests, lint with 34 inherited warnings, the focused packaged contract and installed-tarball strict consumers on Angular 20.0.0, 20.3.33, 21.2.25 and 22.2.1. All four light/dark desktop/mobile demo and catalog-marker checks pass.

Hosted QA follow-up fixes literal ng-content markup in initially empty textareas. Projected text is read outside the raw-text element, and textarea initialization, post-input defaults, controlled release and native reset follow observed React behavior. The shared field restoration queue is now lifetime-owned so callback destruction cannot write to a detached Input or Textarea; a scoped projection observer is also disposed. The native configuration example matches the actual React project/region/cache/TLS data and submit behavior. See hosted-qa.md for current browser, package and deployment evidence and remaining pixel/animation scope.
